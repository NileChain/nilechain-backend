# AgriLink Backend Structure

Chosen shape: a 4-project layered solution.

Why this is the simpler option: it keeps controllers, services, domain models, and EF/data concerns physically separated without introducing CQRS, MediatR, feature slices, or extra abstraction that would slow down a mid-level team.
